# フィードバック学習コマンド

人間のフィードバック（興味/必読チェック）からガイドラインを改善します。

## 実行手順

1. **フィードバックを収集**
   Notion MCPを使用してReaderデータベースから以下の記事を取得:
   - AI_Status が設定済み（審査済み）
   - 興味 または 必読 がチェック済み（人間のフィードバック）

2. **パターン分析**
   以下の観点で分析:

   ### AIが除外したが、人間が良いと判断した記事
   - ドメイン: 信頼度を上げる候補
   - キーワード: 推奨キーワードに追加候補
   - 除外ルールの見直し

   ### AIが推奨したが、人間が興味なしの記事
   - パターンを記録（除外候補）
   - ドメインの信頼度を下げる候補

3. **ガイドライン更新提案**
   分析結果に基づいて更新提案を作成:
   - ドメイン信頼度の変更
   - キーワードの追加/削除
   - 新しい除外パターン

4. **学習データを保存**
   `.context/learning-data/`に分析結果をJSONL形式で保存:
   ```jsonl
   {"date": "2025-01-04", "article_id": "xxx", "ai_status": "除外", "human_feedback": "興味", "title": "...", "domain": "..."}
   ```

5. **ガイドライン更新**
   人間の承認を得た上で`.context/article-review-guidelines.md`を更新。

## 引数

- `--period N`: 過去N日間のフィードバックを分析（デフォルト: 30）
- `--auto-update`: 自動的にガイドラインを更新（要確認）

## 出力例

```
## 学習完了

分析対象: 過去30日間のフィードバック
- AIが除外 → 人間が興味: 5件
- AIが推奨 → 人間がスキップ: 3件

### 提案

1. ドメイン信頼度変更
   - zenn.dev: 20.4% → 25% に上昇（キーワードxxxの記事が好評）

2. キーワード追加
   - 推奨: "container query"（3件中3件が興味）

3. 除外パターン追加
   - "xxx tutorial"（2件中0件が興味）
```
